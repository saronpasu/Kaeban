# Kaeban（替え盤）

替え盤とは、ChatGPTに物語を作らせて体験してもらう遊びです。

このリポジトリは、Kaeban Pluginの公開Previewです。現在のPreviewバージョンは `0.1.17-preview.1` です。完成版ではなく、遊びながら育てています。

## 遊ぶ

Pluginを有効にした通常のChatGPTで「替え盤で遊ぼう」と話しかけてください。チュートリアル、標準コース、自由に遊ぶの三つから選べます。MCPや外部サービスは必要なく、案内から実走までChatGPT内だけで遊べます。

- [短い遊び方](plugins/kaeban/skills/play-kaeban/references/usage.md)
- [詳しい遊び方](plugins/kaeban/skills/play-kaeban/references/manpage.md)

## このGitHubについて

ここでは実装を読み、改造・派生し、開発履歴をたどれます。不具合、観測、フィードバックも受け付けます。普通に替え盤を遊ぶためにGitHubを見る必要はありません。

- [不具合を報告する](https://github.com/saronpasu/Kaeban/issues/new?template=bug-report.yml)
- [観測・フィードバックを届ける](https://github.com/saronpasu/Kaeban/issues/new?template=observation-feedback.yml)
- [Issuesを見る](https://github.com/saronpasu/Kaeban/issues)

公開文書： [Customer Support](https://saronpasu.github.io/Kaeban/support/) · [Privacy Policy](https://saronpasu.github.io/Kaeban/privacy/) · [Terms of Service](https://saronpasu.github.io/Kaeban/terms/)

報告では、何をしたか、何が起きたか、期待していたこと、可能なら関連する会話部分を教えてください。不具合と、まだ良し悪しを決めない観測は、分けられる範囲で分けてください。

## 謝辞

Kaeban（替え盤）は「多重人格TRPG ジキルとハイドとグリトグラ」の思想に強く影響を受けています。ルールを移植したという意味ではなく、物語を複数の主体で作り、体験する遊びについて大きな示唆を受けました。
