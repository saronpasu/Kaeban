Kaeban Privacy Policy

This policy describes Kaeban itself. It does not describe or replace the privacy practices of OpenAI, ChatGPT, GitHub, or any other platform.

Data handled by Kaeban

Kaeban is a skill-only Plugin made of instructions and supporting text files. It has no Kaeban-operated server, MCP connection, external service integration, user account system, analytics, advertising, or payment function.

Kaeban does not independently collect, store, sell, or transmit personal data. The Plugin guides ChatGPT in conducting the game within the conversation where it is used.

ChatGPT conversations

Your prompts and generated responses are handled by the ChatGPT product you use, subject to the terms, privacy policy, workspace settings, and data controls applicable to that product. Kaeban does not receive a separate copy of those conversations.

GitHub Issues

If you voluntarily submit a support request, bug report, observation, or conversation excerpt through GitHub Issues, that content is provided to GitHub and may be publicly visible. GitHub's own terms and privacy practices apply. Remove personal, confidential, or sensitive information before posting.

Changes

This policy may be updated if Kaeban's actual features or data practices change. The effective date below identifies this version.
