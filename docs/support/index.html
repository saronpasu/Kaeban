Kaeban Customer Support

Kaeban is a Preview, skill-only ChatGPT plugin for playing a collaborative story game. It does not require a Kaeban account, payment, MCP server, or connection to an external service.

Get help or report a problem

Use the Kaeban GitHub repository for support:

  • Report a bug
  • Share an observation or feedback
  • Review existing issues

Please include what you did, what happened, what you expected, the Plugin version, and only the relevant conversation excerpt. Remove personal, confidential, or sensitive information before posting.

Scope of support

Support covers the Kaeban Plugin and its play instructions. Questions about a ChatGPT account, billing, availability, or the ChatGPT service itself should be directed to OpenAI through its own support channels.
